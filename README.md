# M Motors

Projet de refonte de l'application web M Motors dans le cadre du Bloc 3 Développer une solution digitale (spé Python).

## Objectif
Développer une application web permettant :
- la consultation du catalogue de véhicules
- la distinction achat / location longue durée
- l'inscription et la connexion des utilisateurs
- le dépôt d'un dossier 100 % dématérialisé
- le suivi de l'avancement du dossier
- la gestion back-office des véhicules et des demandes

## Stack prévue
- Front-end : HTML / CSS / JavaScript
- Back-end : Django
- Base de données : PostgreSQL
- Déploiement : cloud / PaaS

## Structure actuelle
Le dépôt contient actuellement l'intégration front-end statique qui servira de base à l'intégration Django.
